# simple-recipe-browser-45281-45290

This workspace contains a Next.js frontend for a simple recipe browser. It showcases:
- Ocean Professional theme (blue and amber accents) with accessible components
- Home page with search and recipe list
- Recipe detail page using a dynamic route
- Mock in-memory data source (no backend required)
- Optional environment variables wiring (e.g., NEXT_PUBLIC_API_BASE)

Navigate to frontend/ to run the app.
